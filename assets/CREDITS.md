# 素材来源与授权登记

> 本项目使用的所有第三方美术 / 音效素材都必须在此登记：文件名、作者、来源链接、授权协议。

## 当前版本：程序化生成，无第三方素材

当前所有视觉与音频资源均为**代码生成**，不依赖任何外部素材文件，因此无版权问题：

- **美术贴图**：`js/sprites.js` 用 HTML5 Canvas 程序化绘制（主角、冲锋兵、枪手、Boss、云、雪山、树等）。
- **地块 / 背景 / 特效**：`js/level.js`、`js/main.js` 中用 Canvas 绘制。
- **音效**：`js/audio.js` 用 WebAudio API 实时合成（射击、命中、受伤、拾取、变身、胜负等）。
