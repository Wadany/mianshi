# 混乱大枪战 · Web 版

一款模仿 4399《混乱大枪战》的横版 2D 枪战网页小游戏。纯前端实现（HTML5 Canvas + 原生 JavaScript），托管于 GitHub，通过 GitHub Pages 发布，打开链接即玩，无需安装。

## 🎮 在线试玩

GitHub Pages 发布后地址：`https://wadany.github.io/mianshi/`

## 🕹️ 操作

| 输入 | 操作 |
|------|------|
| `A` / `D` | 左右移动 |
| `W` / `空格` | 跳跃 |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 射击 |
| `1` / `2` / `3` | 切换武器（手枪 / 冲锋枪 / 霰弹枪） |
| `左 Shift` | 变身（放大变圆；此形态开枪有后坐力把角色推飞） |
| 点击屏幕 | 开始游戏 / 再来一局 |

## ✨ 已实现功能

### 玩法与操作
- Canvas 渲染 + 游戏主循环（按 deltaTime 更新，帧率无关）
- WASD 移动、重力、跳跃、平台碰撞（含 coyote time 手感优化）
- 鼠标瞄准，朝鼠标方向射击
- 左 Shift 变身形态（放大变圆 + 开枪后坐力推飞）
- 受伤无敌帧、掉进坑即死

### 战斗系统
- **3 种武器**：手枪（无限弹）、冲锋枪（连发）、霰弹枪（扇形多弹丸），数字键切换
- **敌人 AI**：冲锋兵（贴身冲撞）、枪手（保持距离射击）、Boss（扇形弹幕 + 冲撞）
- 子弹命中判定、敌人受击闪白与血条、击杀粒子特效
- **掉落系统**：敌人死亡概率掉落回血包 / 弹药包

### 关卡与场景
- **超大地图（9600px，为初版的 5 倍）**，起伏地形 + 坑洞 + 高低错落的跳跃平台
- 多层视差背景：天空渐变、雪山、云、树，营造冒险感
- 程序化生成的角色 / 敌人 / 地块贴图（无需外部素材，风格统一、无版权问题）
- 终点旗帜：抵达即通关

### 系统
- 完整状态机：菜单 → 游戏 → 胜利 / 失败结算
- 得分、击杀、探索进度、用时统计
- WebAudio 程序化合成音效（射击、命中、受伤、拾取、变身、胜负）
- localStorage 记录最高分

### 后续可扩展（PRD 规划）
- [ ] 更多武器 / 敌人 / 多关卡切换
- [ ] 无尽波次模式
- [ ] 二段跳、冲刺等进阶操作
- [ ] 移动端触屏适配

## 📁 目录结构

```
mianshi/
├── index.html          # 入口，GitHub Pages 读它
├── PRD.md · README.md
├── css/style.css
├── js/
│   ├── config.js       # 所有可调数值（改这里调参：武器/敌人/难度/地图）
│   ├── sprites.js      # 程序化生成贴图
│   ├── audio.js        # WebAudio 音效
│   ├── input.js        # 键鼠输入
│   ├── weapon.js       # 武器与子弹
│   ├── pickup.js       # 掉落物
│   ├── enemy.js        # 敌人与 AI
│   ├── player.js       # 主角（移动/跳跃/碰撞/射击/变身/受伤）
│   ├── level.js        # 关卡、平台、视差背景、终点
│   └── main.js         # 状态机与主循环、战斗判定、HUD
└── assets/
    ├── images/ · audio/
    └── CREDITS.md      # 素材来源说明
```

## 🚀 本地运行

```bash
# 用任意静态服务器（推荐，避免浏览器本地文件限制）
python -m http.server 8000
# 打开 http://localhost:8000
```

## 📦 部署到 GitHub Pages

1. 推送代码到 GitHub 仓库。
2. 仓库 **Settings → Pages**。
3. Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。
4. 稍等 1~2 分钟即可通过 Pages 地址访问。

## 🎨 关于美术素材

当前版本所有贴图（角色、敌人、Boss、地块、山、云、树）均由 `js/sprites.js` **用 Canvas 程序化生成**，音效由 `js/audio.js` 用 WebAudio 合成，因此不依赖任何外部素材、无版权问题、加载快。若日后替换为图片素材，请在 `assets/CREDITS.md` 登记来源与授权。
